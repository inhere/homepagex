前端资源未内嵌到这个二进制里

这是占位页面。当前二进制在编译时没有带上 -tags embedfrontend， 因此内嵌的是占位资源，而不是真正的前端界面。

两种修复方式（任选其一）：

make build                 # 先构建前端，再带 -tags embedfrontend 编译

# 或者：自己构建前端，并让 frontend_dir 指向构建产物
pnpm --dir frontend run build
go build -tags embedfrontend -o homepagex ./cmd/homepagex

运行时只要配置里的 frontend_dir 指向的目录里存在 index.html，就会优先使用该目录，内嵌资源仅作兜底。
